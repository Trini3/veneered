# Veneers

Disclaimer: While the mod has been heavily tested and the code has been reviewed before release, this mod was made with a large amount of help from AI. If you do not want to use a mod made with AI, I would suggest finding another mod with a similar function made without it.

Small Fabric mod that adds frame/template blocks that can be given the texture of any block to ensure model variety for builds, with the aim of keeping up to date with the latest Minecraft Java version that is supported by Fabric. Recipes are all viewable in JEI, most can be made via the stonecutter.
